☁️ الحفظ السحابي (JSONBin)

📌 كيف يعمل؟
1. عدّل أي شيء في اللوحة
2. اضغط "حفظ سحابي"
3. يظهر لكل المستخدمين فوراً
4. لا حاجة لرفع أي ملف
— لم يتم الحفظ بعد —
⚙️ إعداد أول مرة:
1. اذهب إلى jsonbin.io
2. أنشئ حساب مجاني
3. Create Bin → الصق: {"version":1}
4. انسخ Bin ID
5. Settings → API Keys → Create Master Key
6. الصق القيمتين بالأسفل
